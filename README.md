# 🖥️ Meu Portfólio — Desenvolvedor Front-End & Full Stack

Este é o meu portfólio profissional, desenvolvido recentemente para apresentar meus projetos, habilidades e trajetória na programação. O objetivo é oferecer uma experiência moderna, fluida e visualmente marcante, utilizando animações suaves, design responsivo e uma navegação intuitiva.

---

## 📌 Mapa do Projeto

### 🔹 1. Hero Section
- Apresentação com nome, função e chamada principal.
- Botões animados com efeito hover.
- Destaque visual com animação de entrada.

### 🔹 2. Sobre Mim
- Resumo sobre quem sou e minha jornada na programação.
- Tecnologias e ferramentas que domino.
- Animações que aparecem conforme o usuário rola a página.

### 🔹 3. Projetos (My Projects)
- Cards interativos listando meus principais projetos.
- Cada card contém:
  - Imagem de demonstração
  - Título e breve descrição
  - Tecnologias utilizadas
  - Botões para:
    - Acessar código no GitHub
    - Ver projeto online (quando disponível)
    - Abrir galeria de fotos do projeto
- Mensagens de feedback via Toastify (ex.: ao tentar acessar um repositório privado).
- Sistema de galeria com:
  - Modal animado
  - Imagens carregadas sob demanda (lazy loading), só quando a galeria é aberta
  - Navegação entre imagens
  - Fechamento por clique externo

### 🔹 4. Habilidades (Skills)
- Lista visual de tecnologias (HTML, CSS, JS, TS, React, Node etc.).
- Organização por categorias (front-end, back-end e ferramentas).
- Animação ao entrar na área visível.

### 🔹 5. Contato
- Links diretos para contato: WhatsApp, e-mail, GitHub e LinkedIn.
- Seletor de tema (claro / escuro / sistema), com preferência salva no navegador.
- Links para redes profissionais:

  - GitHub  
  - LinkedIn  
  - WhatsApp

### 🔹 6. Navegação (Navbar)
- Scroll suave entre as seções.
- Menu com animação no hover.
- Versão mobile com transição no abrir/fechar.
- Pré-visualização animada ao passar o mouse (quando aplicado).

### 🔹 7. Rodapé
- Direitos autorais.
- Link para meu GitHub.
- Frase ou mensagem final.

## 🚀 Objetivo do Projeto

Criar um portfólio moderno, rápido e totalmente personalizado para destacar minhas habilidades como desenvolvedor.  
O site será atualizado constantemente com novos projetos, melhorias de design e novas funcionalidades.
